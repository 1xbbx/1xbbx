🚀 一、快速启动（3步）

1. 打开终端，进入项目目录
   cd /workspace

2. 运行启动脚本
   ./start.sh
   
   或者手动启动：
   npm install && npm run dev

3. 打开浏览器访问
   http://localhost:3000

═══════════════════════════════════════════════════

📊 二、主要功能

✅ 数据上传
   - 支持 Excel (.xlsx) 和 CSV 格式
   - 拖拽或点击上传文件
   - 实时数据预览

✅ 数据看板
   - 概览卡片：总播放量、点赞、成交、转化率
   - 趋势图：播放量与成交趋势（双轴）
   - 互动图：Top 5 视频互动分析
   - 转化图：挂车点击与成交对比

═══════════════════════════════════════════════════

📋 三、数据格式要求

您的 Excel/CSV 文件需包含以下列：

必需字段（9个）：
- 视频ID（如：DY001）
- 发布日期（如：2024-01-01）
- 播放量（数字）
- 点赞（数字）
- 评论（数字）
- 转发（数字）
- 收藏（数字）
- 挂车点击（数字）
- 成交单数（数字）

示例文件：
- public/sample-data.csv
- public/sample-data.xlsx

💡 六、常见问题

Q: 上传的数据会保存吗？
A: 数据仅存储在浏览器内存中，刷新页面会重置。

Q: 支持多少条数据？
A: 建议单次分析不超过 1000 条数据。

Q: 列名必须是中文吗？
A: 支持中英文列名，如 "视频ID" 或 "videoId"。

Q: 如何导出图表？
A: 当前版本暂不支持，未来将添加此功能。
